1.1 Unity 是什么

Unity 是一款跨平台的游戏引擎，支持 2D / 3D 游戏开发，一次开发可以发布到 Windows、Android、iOS、WebGL 等多个平台。

Unity 采用 GameObject + Component 的组件化设计，所有物体都是 GameObject，功能通过挂载组件实现。

1.2 核心模块

模块 作用
GameObject 场景中所有物体的基类
Component 挂在 GameObject 上的功能组件
Transform 控制物体的位置、旋转、缩放
MonoBehaviour 脚本的基类，提供生命周期函数
